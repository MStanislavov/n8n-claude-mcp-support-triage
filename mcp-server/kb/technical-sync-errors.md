# Fixing board sync errors

If boards are slow to update or show a sync error, work through these steps.

1. Check that the app is version 5.2 or newer. Older versions can fail to sync after server updates.
2. Sign out of the app and sign back in.
3. Clear the app cache in Settings > Advanced > Clear cache. This does not delete any board data.
4. Check the status page at https://status.tasklane.example for a running incident.

Edits made while offline are kept safely on the device for 7 days and are uploaded when the connection returns.

If the problem continues, contact support with the workspace URL, the device type, the app version and the time the error appeared. This lets the support team find the matching entries in the server logs.
